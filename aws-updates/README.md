# AWS Security Updates Tracker

## Purpose
Weekly tracking of AWS security-related releases from the **AWS Security Blog** and **AWS What's New** feed. Helps keep exam study notes and platform implementation guides current.

## How It Works

1. **Trigger**: Run `@release-tracker` to generate the latest digest
2. **Output**: A weekly file `{year}-week-{nn}.md` is created in this folder
3. **Stale flags**: The agent scans existing `exam-study/` and `saas-security/` files and inserts `<!-- STALE: {title} ({date}) -->` comments at the top of affected files
4. **Follow-up**: Run `@content-updater {service}` on flagged files to refresh them

## Digest File Format

Each weekly digest follows this structure:

```markdown
# AWS Security Updates — Week {nn}, {year}

## Summary
- {count} new features
- {count} updates
- {count} advisories
- Files flagged stale: {list}

## New Features
### {Service Name}: {Feature Title}
- **Date**: {date}
- **Category**: New Feature | Update | Advisory
- **Summary**: {1-2 sentence description}
- **Relevance**: Exam | Platform | Both
- **Link**: {url}

## Updates
...

## Advisories
...

## Stale Content Flags
| File | Reason |
|------|--------|
| exam-study/guardduty.md | New finding type added |
| saas-security/waf/guide.md | New managed rule group |
```

## Sources

- [AWS What's New — Security](https://aws.amazon.com/about-aws/whats-new/security/)

- `@release-tracker` — Fetches latest security releases and produces digest
